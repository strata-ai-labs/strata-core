# stratadb.org — work order (D6, D11, /e/ pages, D1)

Prereq reading: `00-shared-contracts.md`. Three deliverables plus the org sweep,
in priority order. The error pages come first because **shipped binaries already
emit `https://stratadb.org/e/<code>` on every failure** — those URLs must resolve.

## 1. Per-code error pages: `/e/<code>` (urgent — D4 dependency)

Every Strata error carries `docs_url: https://stratadb.org/e/<code>` (e.g.
`/e/not_found.engine.branch`). Serve a page per code.

- **Source of truth**: `strata agents errors --json` from the release binary —
  `data.errors[]` gives `{code, class, retry_policy, commit_outcome, message,
  hint, ref}` for all 176 codes. Generate the pages at site build time from the
  current release's binary (or a checked-in snapshot regenerated by the release
  pipeline); never hand-author them.
- **Page content per code**: the code (title), class, message template, the hint,
  retry policy + commit outcome semantics, and a "still stuck" pointer to
  `strata doctor` and `strata agents errors`. Short is fine — the page exists so
  the URL in every error envelope lands somewhere that teaches.
- **Unknown codes** (older/newer binaries): `/e/<anything>` should fall back to a
  generic "error code reference" page explaining the `<class>.<area>.<detail>`
  scheme and how to dump the registry locally — never a bare 404.
- Codes are dotted (`not_found.engine.branch`) — make sure routing accepts dots
  in the path segment.

## 2. install.sh hardening (D6)

`public/install.sh` is live and its human UX is good. Close the gaps
(coherence findings F3/F4/F5), keeping the flow otherwise intact:

1. **sha256 verification** of the downloaded asset against `SHA256SUMS` from the
   same release. Refuse on mismatch with a clear error.
2. **Version pinning**: `STRATA_VERSION=1.0.0 curl … | sh` and
   `sh -s -- --version 1.0.0`. Default remains the current release.
3. **Release manifest instead of `releases/latest`**: read
   `https://stratadb.org/release.json` — `{version, released, platforms:
   {"<os>-<arch>": {url, sha256}}}` — regenerated by the release pipeline (D7).
   Rate-limit-free and gives agents a stable version endpoint.
4. **Agent/non-TTY mode**: auto-detect `! -t 1` and support `--quiet` — a
   line-oriented epilogue:

   ```
   strata 1.0.0 installed: /home/user/.strata/bin/strata (sha256 verified)
   path: updated ~/.bashrc; for this session: export PATH="$HOME/.strata/bin:$PATH"
   next: strata agents guide
   ```

   Optionally `--json` for a structured equivalent.
5. **Verification step**: end by running `strata doctor` (quiet: check exit code;
   it is non-zero when anything needs attention). `strata --version` now exits 0
   on stdout, but doctor is the real check.
6. **Fix the epilogue** (F3/F5): teach exactly the golden trio —

   ```
   strata                      Interactive REPL (in-memory, nothing written to disk)
   strata ./mydb               Open or create a database at ./mydb
   strata agents guide         Full usage guide (for you or your AI agent)
   ```

   Remove the bare `strata kv put …` suggestion (bare one-shot commands now
   *refuse* by design) and the `strata ai` line (surface doesn't exist in V1).
   The machine-readable canonical list is `strata init --json` → `next_steps`.
7. **No telemetry, no phoning home** beyond the release-manifest fetch.

**CI transcript guard** (P2 — required): matrix {sh, bash, zsh, fish} ×
{ubuntu, macos}, TTY and non-TTY, fresh and re-run (idempotent), pinned and
default. Each run must end with `strata doctor` passing and every epilogue
command exiting successfully. This guard is what makes F3 unrecurrable.

## 3. llms.txt upgrade + docs install matrix (D11)

- **`llms.txt` header**: what Strata is (embedded, SQLite-shaped, six primitives,
  branches + time travel), current version + release date (from release.json).
- **Install matrix**: the exact per-channel one-liners (§5 of the design doc):
  curl, brew, cargo, pip/uv, npm, MCP (`npx -y @stratadb/mcp`), Docker, Action.
  Only list channels that are actually live at publish time.
- **The pointer that ends web search**: "after install, run `strata agents guide`
  — the binary carries complete offline documentation."
- **`llms-full.txt`** = the output of `strata agents guide` from the release
  binary, version-stamped, regenerated per release. Byte-for-byte mirroring means
  an agent can detect skew between site and installed binary.
- Docs install page mirrors the same matrix from the same source strings.

## 4. D1 sweep

install.sh (and any drafted brew formula copies) reference `strata-ai-labs/…` —
all GitHub URLs become `stratalab/strata-core` (releases, issues, source links
anywhere on the site).

## Acceptance

- `curl -fsSL https://stratadb.org/e/not_found.engine.branch` → a teaching page.
- `curl … | sh -s -- --quiet` transcript matches §2.4 above on a clean container,
  ends with a passing `strata doctor`.
- `release.json` validates and matches the latest GitHub release assets + shas.
- `llms-full.txt` is identical to `strata agents guide` output for the stamped version.
- Zero remaining non-`stratalab` GitHub references.
