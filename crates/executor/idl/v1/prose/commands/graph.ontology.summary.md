---
summary: Read the ontology with usage counts.
mcp_description: Use this when the user wants ontology types together with usage statistics - how many nodes declare each object type and how many edges use each link type.
---

Reads the graph's ontology annotated with per-type usage: a node count for each object type and an edge count for each link type. Returns no data before any type has been declared. Accepts `as_of` for time travel.
