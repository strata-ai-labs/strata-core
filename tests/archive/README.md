# Archived Tests

This directory is the canonical local archive for tests that remain useful as
historical evidence but should not run in normal V1 CI.

Each archived test must state:

1. Why it is archived.
2. What V1 decision replaced it.
3. Whether any V1 test inherited part of its intent.

The inventory at `docs/architecture/v1-test-inventory.md` records the action
for each archived test.
